# Two new squad members added to LAN 2026 with self-serve Discord RSVP and class color fixes shipped.

Squad roster for LAN 2026 grew to 18 members with the addition of Joe Baker (#17, Ranger) and Aaron Davis (#18, Mage). Both were added to the static `SQUAD_MEMBERS` array in `src/lib/squad.ts` and pushed to production via Vercel. RSVP for these members will be captured automatically through Discord OAuth — no manual Supabase rows required.

The key architectural insight reinforced this period: squad onboarding is fully self-serve via Discord OAuth once a member is in the static array. This keeps the operational overhead near zero as the roster grows toward LAN 2026.
