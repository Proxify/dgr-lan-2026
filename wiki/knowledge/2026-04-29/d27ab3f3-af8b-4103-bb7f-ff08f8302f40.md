# Squad RSVP is fully self-serve via Discord OAuth

New squad members only need to be added to the static `SQUAD_MEMBERS` array — no manual Supabase rows required. RSVP status is recorded automatically when the member logs in with Discord and submits the form; the RSVP table keys on `discord_user_id`.
